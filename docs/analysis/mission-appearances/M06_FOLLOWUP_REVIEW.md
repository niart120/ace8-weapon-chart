# M6 の航空機未裏付け対応と保護対象の追加確認

確認日: 2026-11-05。基準 HEAD `898f419`。[旧航空機照合一覧](AIRCRAFT_APPEARANCES.md)の M6 に残る未裏付け 5 対応を確認した。同じ資料から判明した HANGAR と BUNKER の差分も記録する。後続のユーザー承認で M6 の TYPHOON・HANGAR を除外し、小型 BUNKER（91）を復帰した。証拠 JSON は変更前の記録として保持する。元テーブルの参照確認とコミュニティ資料の照合であり、実ゲーム測定・配置や陣営の直接解析は未実施。

## 航空機の確認結果

[Ace Combat Wiki の M6 敵一覧](https://acecombat.wiki.gg/wiki/Attack_on_the_Drinwich_Airfield)を検索エンジン保持本文で確認した。同ページはゲーム内観察による部分的な一覧と明記している。名称がないことを非出現の証明にはしない。

| 対象 | 追加確認 | 掲載判断 |
| --- | --- | --- |
| IL-76（93） | 敵一覧に記載。保護対象と離陸後に攻撃可能な輸送機を区別 | M6 を維持。基地付近での攻撃禁止を機種全体の除外へ広げない |
| MI-24（29） | 任務更新後の敵として記載 | M6 を維持。旧未裏付けを解消 |
| MIG-29A（67） | 初期戦闘と増援の両方に記載 | M6 を維持。旧未裏付けを解消 |
| MIRAGE 2000-5（4） | 初期戦闘の敵として記載 | M6 を維持。旧未裏付けを解消 |
| TYPHOON（95） | 任務表に `typn_common` はあるが、敵一覧と追加検索で個別出現を裏付けられない | M6 対応だけ暫定除外済み。他任務は維持 |

[保存済み Gamerch M6 本文](https://gamerch.com/acecombat8/1017952)にも、離陸する輸送機を撃墜して得点できる旨の記載がある。これを Wiki の機種識別と合わせて IL-76 の維持根拠とする。個々の保護機・敵機の生成経路まで解決したものではなく、同じ計算行を使える敵が存在するという掲載判断である。HP・耐性の実測確認とは分ける。

M6 の内部任務表は `DT_NPC_Mission007`。対象 5 行の元 NPC、モデル、HP 差分を照合した。TYPHOON は汎用の `OP1011_typn_01` を参照する。PV 定義や機種置換を根拠にした除外ではなく、個別出現が未裏付けという暫定判断である。

## 施設の新しい差分

| 対象 | 追加根拠 | 反映内容 |
| --- | --- | --- |
| HANGAR（96、HP 35） | 同じ Wiki の一覧が HANGAR を破壊すると任務失敗になると明記 | M6 対応を除外。M7/M23 と行全体は維持 |
| 小型 BUNKER（91、HP 75） | Wiki に BUNKER 1 基・205 点。`BunkerS02_common` → `BPD_BunkerS02_01` の BaseScore も 205 | ユーザー承認により M6 へ再掲載済み |
| 大型 BUNKER（92、HP 150） | `BunkerM01_common` → `BPD_BunkerM_01` の BaseScore は 410。今回の 205 点の記載とは一致しない | M6 の既存除外を維持 |

HANGAR の M6 出典は 4 件で、いずれも同じ表示名と HP 35 を持つ。攻撃禁止施設との配置単位の対応付けは未実施だが、攻略上の保護対象を撃破計算から外す提案である。[M23 攻略](https://www.neoseeker.com/ace-combat-8-wings-of-theve/walkthrough/Mission_23%3A_The_Destruction_of_Expo_City)では格納庫への攻撃手順があるため、HANGAR 全体の除外にはしない。

BUNKER は以前、ユーザーの記憶に基づいて ID 91/92 の M6 を両方暫定除外した。今回の得点一致は ID 91 への対応を支持する新しい材料だが、Wiki の目標を内部 ID に直接結び付ける実測ではない。元 HP 75 と 150 の違いを無視して両方を戻したり、以前の判断を自動的に変更したりしない。今回はユーザーが小型 91 の復帰を承認した。

## 記録と次の調査

[M06_FOLLOWUP_EVIDENCE.json](M06_FOLLOWUP_EVIDENCE.json)に現在の対象値、8 行の M6 元出典、元テーブルのハッシュ、資料の取得方法と要点を保存した。基準ビルドの静的データを参照したもので、現行ゲームとの同一性を保証しない。

今回は航空機の未裏付け 4 対応を解消し、TYPHOON と HANGAR の M6 除外、小型 BUNKER の M6 再掲載を反映した。次は旧一覧の M7 未裏付け対応から継続する。旧 118 件を現在の残件数とは扱わず、既に承認・解決した対応を再び未処理に数えない。

`m06-appearances.test.ts` の変更前失敗を確認してから任務除外規則を更新した。変更後の全 138 テストが成功。対象 3 行の HP・耐性・他任務を保持し、掲載総数は 272 行のまま。大型 BUNKER（92）の M6 除外と M24/M25 掲載も維持する。
