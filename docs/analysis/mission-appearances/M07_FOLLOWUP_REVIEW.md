# M7 の航空機未裏付け対応の追加確認

確認日: 2026-11-05。基準 HEAD `2047540`。旧 [航空機照合一覧](AIRCRAFT_APPEARANCES.md)で M7 の未裏付けだった 7 対応に限定した。EA-6B と LADON の既存掲載判断、HARDENED DEPOT と通常タンクの維持を引き継ぐ。後続のユーザー承認で MI-24 を維持し、未裏付けの残り 5 機種の M7 対応を暫定除外した。証拠 JSON は変更前の記録。

## 確認結果

| 対象 | 元任務定義（内部 M008） | 今回の結果 |
| --- | --- | --- |
| MIG-29A（67） | `m29a_common` | Neoseeker が南東からの増援を機種名付きで記載。M7 の旧未裏付けを解消、維持 |
| MI-24（29） | `OP0013_mi24_MS08` | 攻略本文に敵ヘリの記述があり、M7 専用 NPC もある。ただし機種名での裏付けは未取得 |
| MIG-21BIS（1） | `m21b_MS08` | 専用行名はあるが、機種名での出現裏付けは未取得 |
| IL-76（93）／IL-78（118） | `il76_common`、`OP0055_il78_01`／`OP0055_il78_Ground` | 地上の航空機を攻撃する攻略記述はあるが、輸送機・給油機の個別識別は未取得 |
| MIRAGE 2000-5（4）／QUADCOPTER（94） | `mr2k_common`、`mudr_common` | 個別出現の裏付けは未取得 |

[Neoseeker M7 攻略](https://www.neoseeker.com/ace-combat-8-wings-of-theve/walkthrough/Mission_7%3A_A_Lifeline_in_the_Desert)の検索エンジン保持本文で、南東からの MIG-29A 増援を確認した。同資料には発電所周辺のヘリと戦闘機、飛行場の地上機・離陸機への攻撃もあるが、それを機種名の確認とは扱わない。

[Ace Combat Wiki](https://acecombat.wiki.gg/wiki/A_Lifeline_in_the_Desert)の敵一覧は特殊機のみで、通常機を網羅していない。[保存済み Gamerch 本文](https://gamerch.com/acecombat8/1017955)は飛行場の機体への攻撃と LADON の離陸を記載するが、残る 6 機種を識別できない。[PowerPyx の M7 節](https://www.powerpyx.com/ace-combat-8-all-ace-s-ranks-walkthrough/)の検索で取得できた範囲も、個別機種の追加裏付けにはならなかった。実機映像は確認していない。

英語の任務名・番号と各機種名、日本語の IL-78 やドローンでも検索したが、追加の個別根拠は得られなかった。検索結果にあるプレイヤー使用機の推奨 MIRAGE や UAVT、隣接する M6/M8 の記載を M7 の敵出現へ流用しない。

## 承認後の掲載判断

ユーザー判断により MI-24（29）は維持し、IL-76（93）・IL-78（118）・MIG-21BIS（1）・MIRAGE 2000-5（4）・QUADCOPTER（94）の M7 対応を暫定除外した。資料で裏付けられた MIG-29A（67）も維持する。元の HP・耐性・固定 ID・出典・他任務は変更していない。

M6 の HANGAR のような攻撃禁止の明示や、機種の誤対応を示す反証はない。今回の除外は資料の省略を非出現と断定したものではなく、ユーザー承認に基づく掲載範囲の判断である。MI-24 についても、ユーザーが掲載維持を選んだことと、機種名での資料の裏付けを得たことは区別する。

[M07_FOLLOWUP_EVIDENCE.json](M07_FOLLOWUP_EVIDENCE.json)に 7 対象・8 元出典と元テーブルのハッシュを保存した。テーブル基準ビルドの参照確認であり、現行ゲームでの配置・陣営・撃破可否の実証ではない。今回の 7 対応の掲載判断はすべて完了。

`m07-appearances.test.ts` の変更前失敗と変更後の全 139 テスト成功を確認した。掲載対象数は 272 行のまま。今後は任務ごとの個別相談を繰り返さず、未確認対応をまとめて照合し、変更が必要な候補をまとめて報告する。
