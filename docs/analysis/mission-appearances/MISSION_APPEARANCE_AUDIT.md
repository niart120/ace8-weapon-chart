# ミッション出現対応のコミュニティ突合監査

## 対象と結論

2026-11-04、実装コミット `090e3ba` を対象とした調査。以下の集計と照合一覧は修正前の記録。調査後のユーザー確認に基づく変更は「調査後の確定事項」に記載する。

現行の `missionIds` は「敵として出現する任務」ではなく、主に「任務テーブルに定義がある任務」を表している。この違いを未検証事項として記録しながら、そのまま敵の絞り込みに使った実装判断が誤りだった。M3のX-40だけを削除しても解決しない。

全30任務のGamerch攻略本文を読み、航空機本体235対応を個別に照合した。308掲載対象の全736対応について元定義も棚卸しした。地上目標・艦艇・部位は、明示された護衛対象と対応生成の問題を横断確認したもので、全件の実出現を実証したものではない。PROLOGUEには現在の掲載対応がない。ゲームの実行・映像による全配置確認は行っていない。

`target-index.py` は任務差分を持たない部位に、親の全任務を無条件に加える。親IDが複数任務をまとめている場合、任務固有の装備構成まで他任務に広がる。

| ID223 MANPADS《CONTAINER SHIP》 | M16 | M2・M3・M23・M27 | 親がID12であるため、偽装貨物船以外へも広がる。M2の味方船への拡張を含む |

## 修正方針

1. **任務の敵一覧を、任務テーブルの定義一覧から分離する。** 出典の `sourceRefs` は維持し、掲載可否は任務とNPC行単位で判定する。同じID・機種でも任務ごとの所属が異なる。
2. **確認済みの誤対応・非敵対象から修正する。** M3のX-40と7非敵対応を優先する。全任務共通の機種削除や、記事に記載がない行の一括削除はしない。
3. **PVとイベント出現を別途審査する。** PVの3特殊部隊対応は除外候補。M28のX-40などは存在を否定せず、攻撃可能な対象としての掲載可否を決める。
4. **部位継承を限定する。** 直接の任務定義がある部位へ親の別任務を無条件に追加しない。共通部位の補完は、実使用する親NPCの子参照を根拠にする。

出典・判断理由・未確認事項は開発用の資料に保持する。UIへ説明文や追加の状態表示を増やして解決する方針ではない。修正時のテストには、M3 X-40の除外、M20/21の護衛対象除外、M3のMiG-21bisと条件付きF/A-18Cの維持、PODARGEの任務別装備の分離を含める。
