## 今後の進め方（2026-11-05）

ユーザーから、残る 23 任務すべてで同じ個別確認を繰り返すのかとの指摘を受けた。任務ごとに区切って判断を求める運用をやめ、既存記録と現行の掲載対応をまとめて照合する。通常の維持判断はまとめて報告し、相談は除外・復帰・計算方法の変更が必要な候補に絞る。資料に名前がないだけの未確認と、攻撃禁止・非敵・誤対応の具体的根拠があるものを分ける。承認済みの判断は、新しい反証が出ない限り再度開かない。M8 以降の全対応を確認済みと扱うものではない。
