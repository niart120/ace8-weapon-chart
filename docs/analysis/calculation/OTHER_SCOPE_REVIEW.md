UNKNOWN の M26 再掲載は [AIRCRAFT 調査](AIRCRAFT_SCOPE_REVIEW.md)で反映済み。498 の除外案を 410 の再除外や無敵の断定へ広げない。SHUTTER の開閉状態、SWARM DRONES の群体処理も今回の再検証対象ではない。
