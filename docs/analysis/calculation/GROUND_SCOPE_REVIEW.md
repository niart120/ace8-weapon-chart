## コミュニティ資料との照合

[Ace Combat Wiki の M19](https://acecombat.wiki.gg/wiki/Clearing_the_Lighthouse) は、冒頭の CLIMBER の停止・攻撃と敵一覧への掲載を記載する。M19 の CLIMBER を残す根拠になる。本体と残骸を同じ表示行にしている現在の元データは、`DT_NPC_Mission020/Climber` と `Climber_Debris` の両方で `climber_WPDur_000` を参照する。内部表番号 020 は表示 M19 に対応する。

基本行と M19 行はともに HP 100。対地・対艦ミサイルの直撃倍率は基本 1、任務時約 0.2 で、爆風倍率は両方とも約 0.2。したがって、両行は数値の重複ではない。M19 で基本耐性が使われるという証拠がないため、任務なし行へ M19 を追加する案も採らない。残骸に独立した撃破用途があるかは未確認。

[初心者ガイド](https://al-gest.com/?p=271142) は XSAM に言及するが、具体的な任務や敵一覧を示していない。これだけでは ID 478 の実出現を特定できない。掲載中の EX-SAM（225）は `GR040_exsam_01` という別モデルで、M17/M23 の任務参照がある。XSAM の暫定除外を EX-SAM へ適用しない。

[CIWS の解説](https://acecombat.wiki.gg/wiki/CIWS) で見つかった AD TANK の説明は ACE7 の段落に属する。ACE8 の敵出現の根拠として流用しない。PUSHBACK TRUCK は、今回の英名・モデル名による検索では該当する敵出現資料を得られなかった。
