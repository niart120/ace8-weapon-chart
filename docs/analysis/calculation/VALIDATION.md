## 参照資料なしの検証

コミット4f1f6eeのGit管理ファイルだけを `.cache/reference-free/` へ展開し、検証コピー専用のnode_modulesをロックファイルからオフライン導入した。元の作業場所の依存とは共有していない。`docs/initial/ref/` と `data/local/` が存在しないことを明示的に検査した。

その作業コピーで `pnpm test`（77件）と `pnpm build` が成功した。通常テストは配信用JSON・固定の検証例だけを使い、元の参照資料を読み込まない。元資料は移動・削除していない。

通常の配信物と参照資料なしの配信物の双方で、`sourceRefs`・`data/local`・`DT_NPC`・`BlueprintClass` の文字列が含まれないことを確認した。生成専用の出典検査は生成スクリプトへ分離している。Git管理対象にもdata/localとdocs/initial/refが入っていない。

## 制限と環境の修復

初期状態はテスト未登録、既存ui_labels.jsonの整形不一致があった。pnpm 12.4.1のラッパーにはnativeバイナリを配置するインストール処理が未適用だったため、パッケージ付属のinstall.jsを実行し通常のpnpm起動を回復した。最終検証はpnpm 12.4.1を使用している。最初に一時利用したpnpm 10の結果を最終成功として数えていない。

ゲーム内測定、全任務イベントと全レベル配置の実行、基準ビルドと現行ビルドの全データ一致、実スマートフォンのタッチ操作は未確認。[計算調査](CALCULATION_EVIDENCE.md)と[マスタ照合](MASTER_AUDIT.md)に範囲を分けて記載する。

最終ビルド: CSS 7.43kB、JavaScript 456.37kB（gzip 86.08kB）。型検査・Lint・整形確認も成功。ブラウザーの計算API呼び出しを必要とせず、確認したリクエストはローカル配信元だけだった。

参照資料なし確認の初回にnode_modulesをjunctionで共有したところ、pnpmの管理情報が検証コピーを参照した。共有リンクを取り除き、元の依存ディレクトリを.cache内へ退避してロックファイルから再構築した。その後、元の作業場所と検証コピーの両方で独立した依存を使用し、指定チェック・77テスト・ビルドを再実行して成功を確認した。元の場所ではChromeの2シナリオも再成功した。
