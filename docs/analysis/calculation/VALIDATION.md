# 初期実装の検証記録

実施日: 2026-11-03。Windows・Node.js 24.13.0・pnpm 12.4.1・Python 3.12。

## 自動検証

型検査、Lint、整形確認、Vitest 76テスト、Viteビルドを実行。生成の不正入力・統合不一致・参照切れ・未確認と0の区別、固定ダメージ48トレース、HP合成、状態・保存復元、DOM操作を検証した。

同一のローカル対応表から2回再生成し、3マスタのSHA-256が一致した。生成時にOxfmtのAPIで整形し、再生成結果を手修正していない。

## 実ブラウザー

Chrome 156.0.8078.74でPlaywrightの2シナリオを実行し、PCとスマートフォンのスクリーンショットを目視した。実機スマートフォンは使用していない。

時刻はローカル開発サーバーとPlaywrightからの操作時間を含む1実行の実測値であり、統計値や実機での保証ではない。操作を妨げる停止は確認せず、キャッシュ・Worker・仮想化は導入しなかった。

PCでは34兵装列、348行へ拡張し、目標名列・見出しの固定、HP列が固定されないこと、横・縦スクロール、キーボードの横スクロールを確認した。検索中の分類全解除、再読込での選択保持、パネル初回フォーカス、Escapeで閉じた後の元ボタンへの復帰も確認した。パネル初回フォーカスの不具合は修正後に再実行した。

スマートフォン相当では3列初期表示、設定パネル、Rookie MSLと機銃3種の同時選択、多数列の横スクロール、兵装全解除の保存・復元、目標全解除、全体リセットを確認した。画面全体の横はみ出しはない。長い部位名は折り返しを許容し、選択欄にはHPを数値で併記する。

ゲーム内測定、全任務イベントと全レベル配置の実行、基準ビルドと現行ビルドの全データ一致、実スマートフォンのタッチ操作は未確認。[計算調査](CALCULATION_EVIDENCE.md)と[マスタ照合](MASTER_AUDIT.md)に範囲を分けて記載する。
