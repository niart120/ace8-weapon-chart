現状: TypeA・TypeB・TypeCは別IDの兵装として `WEAPONS` で選択し、同時に別列で比較できる。当面の対応は基礎威力5・15・10。

当面の方針: 基礎名は共通の `GUN` とし、Typeを含む選択肢・列ラベルの記法は別途決める。`[威力]<発射レート>` は未採用の候補として保持し、全体完成後に見直す。
