## 4. 絞り込み・選択・表示

元行へ除外、部位、任務差分、選択任務、検索を適用した後に集約する。検索は新名・旧名・親名で行う。任務と所属を別々の集合にして掛け合わせない。

選択保存は元IDの集合。サイドバーでは分類・細分類ごとに候補を集約し、その行の操作は当該分類・検索内の元行だけに作用する。比較表では選択済みかつ現在の対象範囲にある元行を全分類横断で一行にまとめる。複数の分類に属する比較単位を単一分類へ再分類しない。

一括選択・MISSION変更・INCLUDE変更の既存動作を維持する。候補の一部選択は混合チェックで示す。結果表のID・並び順・名前は比較単位ごとに固定し、絞り込みで代表が変わっても名前は変えない。所属表示には現在の候補または選択に含まれる元行の旧名・分類・任務を示す。候補では名前のツールチップ、比較表では名前を開く詳細表示で確認できる。

| 性能要件 | 方針 |
| --- | --- |
| 集約 | 対象約500行をMapで一回走査。結果計算前に同値行をまとめる |
| 再生成 | ローカル抽出がある環境では同じ規則から再現。テスト・ビルドにゲームや抽出資料を要求しない |
