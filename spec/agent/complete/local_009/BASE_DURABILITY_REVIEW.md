# 任務別耐性を省略した場合の比較

## 1. 目的と条件

2026-11-06。掲載269行を対象に、耐性を簡略化した場合の統合可能数を試算した。アプリ・配信マスタは未変更。HP、isAir、roleGroup、standardDamage、掲載範囲は維持し、耐性だけを変更する仮定で比較した。ゲーム内での適用可否を確認した調査ではない。

| 条件 | 定義 | 同じ基本名・計算属性の組数 |
| --- | --- | ---: |
| 現行 | 現行値をそのまま同値統合 | 228 |
| A | 任務表のWeaponDurabilityId上書きを無視し、NPCの耐性を採用 | 221 |
| B | Aに加え、NPC_WPDur_001_MS25day2をNPC_WPDur_000へ置換 | 214 |

Bの置換は比較用の明示的仮定であり、「そのNPCの真の基本値」や「実ゲームで適用されない」という認定ではない。NPC側の任務専用設定を全件無効化する一般規則を発見したわけでもない。

## 4. M25差分の訂正と条件B

AA GUN 343の出典はNPC `VE001_gors_palma_aagun_MS25day2`、NPC耐性 `NPC_WPDur_001_MS25day2`、任務耐性 `None`。362/366も同じ耐性IDをNPC側に持つ。通常側は `NPC_WPDur_000`。従来の「任務別耐性」という説明は任務表上書きと任務専用NPC設定を混同していた。

AではM25の艦載差は残る。Bでは341/343/344/342/345/361/362/363/364/366/365の11行が追加で変化し、AEGIS、DESTROYER、FRIGATE、AA GUN、CIWS、NAVAL GUN、VLSがそれぞれ1条件減る。Aから7減の214組。AA GUNは9→8条件となる。

## 5. AA GUNの表示案への影響

名称候補はユーザーのAIR/GROUND/SHIP形式を検討する。日本語訳・倍率説明を項目名へ追加する以前の案は撤回する。

| Bでも残る条件 | HP | isAir / roleGroup | ID |

| PODARGE | 10 | true / air | 183 |
| PODARGE | 20 | true / air | 382 |
| CELAENO | 40 | true / air | 278 |
| 地上単体 | 20 | false / ground | 32 |
| 艦載通常・M25統一 | 20 | false / ship | 244/124/126/64/60/58/53/343/362/366 |
| PODARGE / LAND DESTROYER | 35 | false / ship | 378/311 |
| LAND BATTLESHIP 1～3 | 40 | false / ship | 148/248/227 |
| TRIUMPHANT | 35 | false / none | 483 |

AIR/GROUND/SHIPをロール補正区分の意味で使う場合、陸上戦艦はSHIPとなり、TRIUMPHANTは3区分に収まらない。見た目・所属を意味する場合は既存categoryや親名から補正を推測しないこと。382はSHIP分類だがisAir=true / roleGroup=airのままであり、親が水上版だから補正も変わるとは断定できない。

3名称への整理と3計算行への統合は別。HPを既存列に置けば同名複数行を表現できるが、SHIP系HP35は378/311と483で補正・耐性も異なる。3区分を主に使い、特殊個体のみ親名を残す案が可能。名称の確定は今回行わない。
