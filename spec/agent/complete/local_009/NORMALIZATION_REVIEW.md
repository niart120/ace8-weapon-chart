# ターゲット項目の正規化調査

最新の方針は [統合対象と保持する差の再整理](CONSOLIDATED_DECISIONS.md) を参照。呼称変更は保留、M25耐性の採否は別件、PODARGEは空中・水上とも維持。本書の表示名・親タグ省略案は未採用。

## 1. 概要

### 1.1 目的・背景

同じ比較対象が所属・モデル・任務ごとに分かれている行を抽出し、計算差を失わずに表示をまとめられる範囲を調べる。AA GUN / SAM / MSL PALLET に限定せず、現行の全掲載対象を調査した。2026-11-06、基準 HEAD `7292460`。アプリ・掲載マスタは変更していない。

### 1.2 用語定義

| 用語 | 定義 |
| --- | --- |
| 基本名 | 現行名から `《親名》` と末尾の任務注記を外した名前。(Front)、(EV)、(CORE)、(SHADOW) などは保持 |
| 計算属性 | HP、全18耐性倍率、isAir、roleGroup、standardDamage |
| 統合候補 | 同じ基本名で計算属性が完全一致する組。物理的に同じ個体という意味ではない |
| 出典 | catalog のテーブル・行参照。任務表の参照は実ゲームでの配置・敵対・攻撃可否の実証とは区別 |

### 1.3 結果・期待効果

| 項目 | 結果・意味 |
| --- | --- |
| 調査母数 | 全506行のうち掲載269行。除外237行は統合対象に含めない |
| 出典照合 | 掲載行の1,092参照すべてについて解決済み計算属性と配信値の一致を確認。元テーブルの NPC・モデル・任務設定も記録 |
| 同名・同値 | 23組・64行。計算属性単位なら41行減の228行になる。ただし所属・フィルター・任務差分の扱いを決める前の上限値 |
| 同名・異値 | 32基本名。差のある属性とIDごとの値を全件記録 |
| 異名・同値 | 41組。別機種・別種類も混ざるため、表示行の自動統合対象にはしない |
| 親タグ省略 | 同じ基本名が1計算条件に収まる14種類を抽出。検索用の親情報は保持する提案 |

### 1.4 着手条件・範囲

今回は静的データの調査。統合実装、表示名の確定、選択保存形式の変更、掲載判断の変更は行わない。全候補のイベント・Blueprint 実行経路を再解析したものではない。既存の計算範囲を前提にした「比較表での同値」である。

## 3. 設計方針・統合判断

### 3.1 同じ基本名・同値の23組

[全件表](CANDIDATE_TABLES.md)を正本となる抽出一覧とする。以下はその判断分類。IDの組は同値グループごとに区切る。

| 判断 | 対象・ID | 根拠と残す情報 |
| --- | --- | --- |
| 同一所属内の統合を推奨 | MSL PALLET 201/202 | 親200、M12、分類、計算属性一致。rpdna/b/c の3モデルは同じ表示名キー・HP20・耐性設定。出典を併合し、表示名は MSL PALLET を候補とする |
| 親を複数保持して比較行を統合 | 陸上戦艦 AA GUN 148/248/227、AIRBURST GUN 150/257/229、VLS 155/254 | 親の型・任務が違う。所属対応を保持すれば同じ計算行として扱える |
| 親を複数保持して比較行を統合 | 艦載 AA GUN 244/124/126/64/60/58/53 と 343/362/366、NAVAL GUN 243/127/63/61/57 と 342/363/365、VLS 246/129、SAM 128/65/309 | 通常とM25耐性差分は別グループ。異なる艦・任務の対応を保持する |
| 所属・分類を保持した表示統合の候補 | AA GUN 378/311、CIWS 374/107/368、DISP. RAIL GUN 380/313/314、SHUTTER 375/108/369、SSM LAUNCHER 379/312、VLS 184/383 と 376/109/370 | AIRCRAFT/GROUND/SHIP をまたぐ。同値を理由に分類を1つに固定しない。DISP. RAIL GUN の313/314だけなら同じ親310・分類であり、先に統合可能 |
| 本体／部位を保持した表示統合の候補 | LAND AEGIS 373/106/367、LAND DESTROYER 377/310 | PODARGEの部位と独立した本体が混在。partOfを代表1件にすると部位非表示の挙動が壊れるため、単一Targetへの上書きは不可 |
| 任務差分の選択仕様を決めて表示統合 | WING SPAR 102/189、BUILDING 80/136 | 前者はLADONのM7差分とPODARGEの部位。後者はM5とM8の任務差分。単一missionVariantには収まらない |
| 内外・任務上書きを保持して表示統合 | PILLAR (Front) 420/419、PILLAR (EV) 422/421 | OUT共通値とINのM27上書き値が一致する。IN基本行500/501は爆弾倍率が異なるため統合しない。Front/EVのHP100/200も残す |

全23組でモデルの `GameObjectDisplayName01` は組内一致した。ただしBUILDINGは空文字一致であり、ゲーム内名称の裏付けではない。他の22組も表示名キー一致だけで同一個体とは判断していない。

既存の [ROLE調査](../../../../docs/analysis/calculation/ROLE_SCOPE_AUDIT.md) では201のロールをnoneへ訂正している。MSL PALLETの旧資料のnull/none差は現行では解消済み。モデル違いだけが残った重複として扱う。

### 3.2 残すべき計算差

全32基本名の差を [全件表](CANDIDATE_TABLES.md) と `CANDIDATES.json.differences` に記録した。主要例は次のとおり。倍率の約表記は説明用であり、抽出比較では丸めていない。

| 対象 | 残す差 | 判断 |
| --- | --- | --- |
| AA GUN / SAM | 地上のroleGroup=ground、艦載のship、航空部位のairなど。AA GUNは20行で9条件、SAMは5行で3条件 | 同じHPでも補正や装備条件で計算が変わるため基本名だけでは統合不可 |
| 艦載AA GUN / NAVAL GUN、AEGIS / DESTROYER / FRIGATEなど | 通常とM25でgun/laser倍率1と0.5 | M25という注記を消して同値に扱わない。名前を変えても任務との対応は残す |
| BUILDING | ID80/136はgun/laser=1、157は約0.2。いずれもHP90 | 80/136は同値、157は別条件 |
| PILLAR | IN基本行500/501はbomb約0.1、OUTおよびM27上書き行は5。FrontはHP100、EVは200 | 内外のモデル差すべてが計算差とは限らない。実際の倍率で分割 |
| PODARGE | ID179はisAir=true、381はfalse。HP720・roleGroup=airは同じ | 空中／地上条件付き装備で変わるため分離 |
| THRUSTER | 488と153は対地・対艦直撃倍率が異なる。爆風倍率は同じ | 直撃と爆風を別々に比較する必要がある |
| WING SPAR / LADON / MAIN ENGINE等 | HPと各耐性の組み合わせが異なる | 「同じ所属名」や通常MSLの必要弾数一致ではまとめない |

`null`、HP非適用、`standardDamage=false` による「?」一致も統合根拠にはしない。今回の23組は全件HPが数値、通常計算可、空中判定・ロール・耐性にnullなしである。

### 3.3 別名だが同値の対象

A-10C / F-22A、地上AA GUN / SAM / APC、GAS TANK / OIL TANK、BREACH / CORE UNITなど41組を別枠で列挙した。これは計算属性の共通化候補であり、機体・兵器・部位の名称を消す表示統合は推奨しない。

括弧などを外して機械的に名前を近づける処理はしていない。PILLARのFront/EV、SHADOW、COREなどは識別情報として残す。異表記が本当に同じ対象かは名前の類似度では確定できないため、異名同値一覧を次の手動確認の入口とする。耐性まで異なる別名同義語は今回の同値抽出では検出できない。

### 3.4 親タグ省略候補

14種類: MSL PALLET、GENERATOR、RADOME、AAM、LAND DESTROYER、SSM LAUNCHER、LASER DESIGNATOR、CASEMATE GUN、BREACH、CORE UNIT、HEAT VENT、RAIL GUN TURRET、LAUNCH TUBE、FUSION REACTOR。

現行掲載範囲では、親タグを外しても同名異値の衝突がない。LAND DESTROYERとSSM LAUNCHERは統合候補をまとめた場合の判断。名前だけで何の部位か伝わるかは別の判断なので、14種類の一括削除を確定したものではない。

省略後もC-130やCELAENOなどの親名で検索できることを提案する。現在の検索は `name` の部分一致だけなので、単にタグ文字列を消す変更では検索性が落ちる。説明表示・所属表示と検索文字列を分ける必要がある。

## 4. 実装仕様に向けた提案

原データの「対象・所属・任務条件」と、比較表の「同名・同計算条件」を分ける。単一の代表IDへ親・分類・任務を上書きしない。

絞り込みと選択は元の関係に対して評価し、その結果を比較行にまとめる案を第一候補とする。所属関係は少なくとも元ID・親ID・分類・部位フラグ・任務差分・任務集合・出典の対応を維持する。親集合と任務集合の直積を作らない。M25のLAND AEGIS系など、同じ名前が複数分類にある場合の選択パネル上の配置は未確定。

実装順の提案は、MSL PALLET 201/202とDISP. RAIL GUN 313/314の同一所属内統合、艦載・陸上戦艦部位の比較行集約、分類横断・本体/部位混在・任務差分混在の扱い、表示名と検索の整理。現行のID保存形式をどう変更するかは実装時に別途決める。
