# 候補フィルター・選択仕様書

## 目的・背景

左サイドバーの選択操作を定義する。MISSION・INCLUDEで比較する対象範囲を指定し、その変更を選択と表へ自動反映する。名前検索は候補を探すために使う。

| 用語 | 定義 |
|---|---|
| 候補 | フィルターを通過した選択肢 |
| 選択 | 表に表示するID集合 |

| 期待効果 | 内容 |
|---|---|
| 任務の比較 | 一度の任務指定で対象が表へ反映される |
| 分類の一括選択 | 検索結果にない対象の手動選択を維持する |

## 妥当性検討と決定

候補だけを絞る旧設計では、M1を指定しても表は125件のままであり、任務の対象を比較する操作が成立しなかった。2026-11-05のレビューとユーザーの採用判断を受け、MISSIONをALL付きの排他選択とし、INCLUDEも選択へ自動反映する。修正前はコミット `ebfbc71` に保存済み。

## 実装仕様

MISSIONはALLまたは一つの任務。ALLは任務を限定しない意味で、内部値は `missionId: null`。別の任務またはALLへ切り替えると、現在のINCLUDEに合う範囲の全対象を選択し、範囲外の選択を除く。同じ項目の再選択では手動の選択解除を復活させない。兵装・ROLE・DAMAGE TYPE・PARTSは維持する。任務表示のチップを解除する操作もALLへの切り替えとする。

INCLUDEはMISSION VARIANTS / TARGET PARTS。変更前後の範囲の差分を選択に反映する。新たに範囲へ入る対象は自動選択し、外れる対象は解除する。両方に残る対象の個別解除は維持する。部位かつ任務差分の対象は両方がONのときだけ対象となる。OFF→ONで再び入った対象は再選択する。

名前検索だけは候補一覧への絞り込み。検索中でも任務・INCLUDEの変更は検索文字列に依存せず範囲全体へ反映する。名称検索は前後空白を除去し大文字小文字を区別しない。分類・中分類の一括操作は検索後の候補のみを対象とする。0件の分類は表示せず、候補0件はNO RESULTSを表示する。対象の個別チェックによる調整は即時表へ反映する。

PROLOGUEは非表示、M14および掲載対象のない任務は指定不可。MISSIONとINCLUDEの範囲外の対象は、保存値に混入していても表に表示しない。計算方式と数値データは変更しない。

保存形式はversion 5。単一のmissionId、INCLUDE、選択ID、計算条件を保存する。旧形式は変換せず初期化。未知・指定不可の任務、型不正の値は保存全体を初期化し、未知ID・重複ID・範囲外の対象選択は除く。全解除は保持する。検索・パネル・アコーディオン・ポップオーバーは保存しない。

パネルの配置と操作は [左サイドバーUI仕様書](SIDEBAR_UI.md) で定義する。
