# 候補フィルター・選択仕様書

## 目的・背景

TYPE/MISSIONの方式切り替えを廃止し、名前検索・ミッション・INCLUDEを候補にのみ適用する。モックではINCLUDEが表にも作用していた。この例外を本実装では廃止し、チェックだけが表の対象を決める。

| 用語 | 定義 |
|---|---|
| 候補 | フィルターを通過した選択肢 |
| 選択 | 表に表示するID集合 |

| 期待効果 | 内容 |
|---|---|
| 操作の予測 | 絞り込んでも表が勝手に変わらない |
| 一括選択 | 見えていない対象を変更しない |

## 妥当性検討と決定

1. ミッションを表へ直接適用する案は、選択とフィルターの二重制御になるため採用しない。
2. INCLUDEだけ表へ適用する旧動作も検索・ミッションとの不一致があるため採用しない。
3. 全IDを初期選択する旧方式はINCLUDE非表示の対象まで表に出すため廃止する。初期対象は非EXCLUDEDかつ部位・任務差分ではない対象のみ。兵装初期値はPC全掲載、モバイル通常MSLを維持。
4. フィルターを解除してもチェックは維持する。絞り込み下の一括操作は候補のみに作用する。選択済みだが候補外の対象も表には残る。候補外も含めて戻す操作は全体リセットとする。

ミッション指定だけで表をその任務の対象へ置き換える操作は提供しない。表を変更するには候補のチェックを変更する。この操作数の増加を受け入れ、検索・ミッション・INCLUDEすべてで選択を保つことを優先する。

パネルの配置と操作は [左サイドバーUI仕様書](SIDEBAR_UI.md) で定義する。

## 実装仕様

候補条件は検索ANDミッションAND INCLUDE。複数ミッションはOR、未指定は全任務。PROLOGUEは非表示、M14および掲載対象のない任務は指定不可。部位かつ任務差分の対象にはINCLUDE両方が必要。名称検索は前後空白を除去し大文字小文字を区別しない。検索結果0件はNO RESULTS。0件の分類は表示しない。

ミッション指定は解除可能なチップを表示する。ポップオーバーを閉じても候補条件は保持。分類・中分類の選択状態判定と一括選択の母集合は現在の候補。個別選択・一括選択とも即時表へ反映。計算方式と数値データは変更しない。

保存形式はversion 4。targetModeを削除。missionIds / showParts / showMissionVariantsは候補条件として保存し、選択IDと独立して復元する。旧version 3は変換せず初期化する。破損・未知ID・保存拒否への既存防御は維持。検索文字列・パネル・アコーディオン・ポップオーバーは保存しない。
