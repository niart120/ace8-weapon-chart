# 左サイドバーUI仕様書

## 目的・背景

モックブランチ `codex/sidebar-rail-mock` の `05f6539` を視覚上の基準とする。左端のアイコンで近接したパネルを操作する。モックの説明文、件数、比較用A案は本体に持ち込まない。

| 用語 | 定義 |
|---|---|
| 操作列 | ミサイル・照準・歯車、最下端の全体リセット |
| パネル | WEAPONS / TARGETS / SETTINGSの非モーダル領域 |

| 期待効果 | 内容 |
|---|---|
| 操作位置 | 開閉してもアイコンが移動しない |
| 閲覧領域 | デスクトップでは表とパネルを並置 |

## 設計・実装仕様

初期は閉じる。同じアイコンで閉じ、別アイコンで切り替える。767px以下は表に重ね、768px以上は表の領域を縮める。パネル幅360px、操作列48px。短い画面でも内容をスクロールできる。閉状態はinert/aria-hiddenでアクセス不可にする。閉じるアニメーション中は直前のパネル内容を保持する。開閉200ms、reduced-motionでは無効。

各パネル上部の見出しは高さ64px。選択パネルの検索は虫眼鏡から同じ行に展開し、入力へフォーカスする。検索終了時は入力を解除して見出しへ戻す。検索・分類の開閉はパネル切り替え時も保持し、再読込では初期化する。Escapeはフィルター→検索→パネルの順で閉じ、操作元へフォーカスを戻す。Tabは表も含め通常移動し、パネル内に閉じ込めない。

SETTINGSはROLE / DAMAGE TYPE / PARTSのアコーディオン。初期は全展開。閉状態の値要約なし。ROLEは2列、DAMAGE TYPEは横並び。PARTSはMSL、SP.MSL、BOMB、GUN / RKT / EMLの順。内容全体で一つのスクロール。区分別リセットは廃止。全体リセットは条件・選択・候補条件・検索・開閉状態・表ソートを初期化し、現在開いているパネルは維持する。

TARGETSのフィルターはアイコン直下のポップオーバー。MISSIONを上、INCLUDEを下に配置。INCLUDEはMISSION VARIANTS / TARGET PARTS。開閉だけでは一覧位置を変えない。外側クリック・Escape・パネルの切り替えで閉じる。画面内に収まり、内容はスクロール可能。SETTINGSには対象フィルターを置かない。

フィルターの選択意味論と保存形式は [候補フィルター・選択仕様書](CANDIDATE_FILTERS.md) で定義する。
