# モバイルメニュー仕様書

## 1. 概要

### 1.1 目的

モバイルで表の横幅を確保し、ヘッダーから既存のピラーとパネルをまとめて開閉する。

### 1.2 用語定義

| 用語 | 定義 |
| --- | --- |
| ピラー | 武器・対象・設定と全体リセットのアイコン列 |
| パネル | ピラーで選択した項目の操作領域 |
| モバイル | 画面幅767px以下。768px以上はPC表示 |

### 1.3 背景・問題

従来のモバイル表示はピラーが常駐し48pxを占有する。モックのピラー単独表示を廃止し、全体を閉じる状態とピラー・パネルを表示する状態の2状態にする。

### 1.4 期待効果

| 項目 | 期待効果 |
| --- | --- |
| 表の幅 | 閉じている間はピラーの48pxの余白をなくす |
| 再操作 | 前回のパネルへ1操作で戻る |

### 1.5 着手条件

ユーザーがモックのデザインと2状態への整理を承認済み。本実装ブランチは `codex/mobile-menu`。

## 3. 設計方針

既存の `section`（表示中のパネルまたはnull）と `lastSection`（最後の選択、初期値weapons）だけで管理する。独立した `menuOpen` は持たない。ピラーの表示は `!mobile || section !== null` から導出する。選択・計算・保存形式は変更しない。

## 4. 実装仕様

- モバイル初期表示は全体を閉じる。高さ72pxのヘッダー左に48pxの操作ボタンを設ける。
- 開くとピラーと `lastSection` のパネルを同時表示。初回は武器。閉じるボタンは×表示にする。
- モバイルの選択済みアイコン再押下は表示を維持。他のアイコンはパネルを切り替える。
- ×で全体を閉じ、ハンバーガーにフォーカスを戻す。Escapeは既存のフィルター、検索の順に閉じ、その後に全体を閉じる。
- 最後のパネルは同一ページ内で保持。再読み込み時は閉じた状態・初回武器に戻る。武器・対象・設定値の保存は既存仕様のまま。
- 開いている間は表を操作不可にし、Tabの移動先をヘッダーの開閉ボタン・ピラー・パネルに限定する。閉じたピラーとパネルは操作・読み上げ対象から除外する。
- PCではピラー常駐、同じアイコンでパネル開閉という既存動作を維持する。
- 画面幅切り替え時も `section` と `lastSection` を維持。PCでパネルを閉じた状態からモバイルにすると全体を閉じる。パネルが開いていればピラーと一緒に表示し、表にフォーカスがあればパネルへ移す。モバイルヘッダーのボタンにフォーカスしたままPC幅へ変更した場合は対応するピラーのアイコンへ移す。
- モバイルではピラーとパネルをヘッダーの下に配置。表とフィルターの高さからヘッダー分を差し引く。動きを減らす設定では開閉アニメーションを使わない。
