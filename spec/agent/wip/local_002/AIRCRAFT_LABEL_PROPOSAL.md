# 敵機設定の識別ラベル仕様と検証結果

2026-11-03。状態: 採用・実装済み。変更前HEAD: `3d2ef88`。本ファイルは同日の検討案を、ユーザーが採用した丸括弧案に更新した。

## 1. 目的と用語

同名・同HPでも計算条件が異なる航空機を識別する。元定義と同梱文字列の静的照合に基づき、実ゲームでの出現保証とは区別する。

| 用語 | 意味 |
| --- | --- |
| 識別名 | 機体名の後ろの丸括弧。今回の値はSHADOWまたはVENTUS |
| 任務ラベル | 末尾の角括弧。既存記法の[M番号]、M25後半は[M25-2] |
| 部位ラベル | 部位名《本体名》。今回の17行はいずれも本体 |

## 3. 設計方針

表記は`機体名 (識別名) [M番号]`。半角丸括弧、角括弧のそれぞれの前に半角空白を置く。通常行は無印、NAMEDは通常行との統合を維持する。

同梱文字列`ContainerCorpsName_Shadow`は`SHADOW`。内部耐性IDのShadowsから複数形の画面名を作らない。ID 305はVENTUS 541・542を統合した行なので、承認済み略記`VENTUS`を使う。同じ耐性IDを持つことだけを理由にSHADOWと呼ばない。

識別名は所属・呼称の区別であり、固定の耐性値を表さない。SU-57 (SHADOW)と同[M26]のUAVT倍率0.25／1は両方維持する。共通行にSHADOW用NPC参照が含まれるだけでは改名しない。
