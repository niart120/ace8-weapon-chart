# ACE COMBAT 8 Weapon Chart

ACE COMBAT 8（キャンペーンモード）の各目標毎の確定数を武器別に一覧表示するWebツールです。

- 公開URL: https://niart120.github.io/ace8-weapon-chart/
- 動作環境: PC・スマートフォン

## 使い方

### 主な機能
- **目標の絞り込み**:
  - 左端の照準アイコンから目標を選択
  - `MISSION` は `ALL` または一つの任務を選び、その範囲の対象を自動選択して表に反映
  - `INCLUDE` の変更で追加対象を自動選択し、範囲外の対象を解除。範囲内の手動解除は維持
  - 名前検索は候補だけを絞り込み、分類の一括選択は検索後の候補だけに適用
- **命中数一覧**:
  - 1発 / 2発 / 3発 / 4発 / 5発以上で色分け表示
  - 各兵装の命中数・名前・HPでの昇順・降順ソートに対応
- **設定の保存**:
  - 選択した目標・ミッションおよび計算条件はブラウザーに自動保存

左端のミサイル・照準・歯車で各パネルを開閉します。全体リセットは左下です。保存形式の変更により旧形式の設定は初期化されます。

### 表中の記号
- `-`: ダメージ無効、またはHP概念のない目標
- `?`: ダメージ計算処理または基礎数値が未確認

### 一部兵装の扱い
- **SFFS / SOD**: 子弾1発あたりの命中数を表示
- **MPBM**: 直撃および爆風初撃のみで計算（継続ダメージ含まず）
- **TLS**: 未対応
- **UAVT**: 未対応

### 注意事項
- ゲーム内データの静的解析値に基づき算出しています。
- 実機における当たり判定、命中可能性、ミッション中の無敵演出は考慮していません。
