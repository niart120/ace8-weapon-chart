# ACE COMBAT 8 Weapon Chart

ACE COMBAT 8（キャンペーンモード）の各目標毎の確定数を武器別に一覧表示するWebツールです。

- 公開URL: https://niart120.github.io/ace8-weapon-chart/
- 動作環境: PC・スマートフォン

## 使い方

### 主な機能
- **兵装・目標の絞り込み**:
  - 分類ごとの選択や名前検索に対応
  - 目標は登場ミッション（`MISSION`）や部位・ミッション固有個体（`INCLUDE`）でも絞り込み可能
- **計算条件の切り替え**:
  - 機体ロール（`ROLE`）・ダメージ種別（`DAMAGE TYPE`）・強化パーツ（`PARTS`）を反映可能
- **命中数一覧**:
  - 1発 / 2発 / 3発 / 4発 / 5発以上で色分け表示
  - 各兵装の命中数・名前・HPでの昇順・降順ソートに対応
- **設定の保存**:
  - 選択した兵装・目標および計算条件はブラウザーに自動保存

### 表中の記号
- `-`: ダメージ無効、またはHP概念のない目標
- `?`: ダメージ計算処理または基礎数値が未確認

### 一部兵装の扱い
- **SFFS / SOD**: 子弾1発あたりの命中数を表示
- **MPBM**: 直撃および爆風初撃のみで計算（継続ダメージ含まず）
- **TLS**: 未対応
- **UAVT**: 未対応

### 注意事項
- ゲーム内データの静的解析値に基づき算出しています。
- 実機における当たり判定、命中可能性、ミッション中の無敵演出は考慮していません。
