# Rajdhani

Indian Type FoundryのRajdhaniをSIL Open Font License 1.1に従って同梱する。ライセンスと著作権表示は`OFL.txt`に収録。

- 配布元: https://github.com/google/fonts/tree/main/ofl/rajdhani
- 取得日: 2026-11-04
- 同梱: Regular（400）、Medium（500）、SemiBold（600）のTrueTypeファイル
- 取得したフォントファイルは改変していない。

アプリではローカルファイルを読み込み、実行時にGoogle Fontsへ接続しない。
